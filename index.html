What is Current Day?

This page will change based on the hour of the day.

This page uses JavaScript to determine the current hour, and presents a different image, custom message, and color based on each of the following times of day:

  • Morning (5am to 12 noon)
  • Afternoon (12 noon to 6pm)
  • Evening (6pm to 11pm)
  • Night (11pm to 5am)

to do this i am using compound if block and selecting ranges and using getHours() methods of date() object

to make changes i use document.getElementById() and document.querySelector() identify items on page to change
